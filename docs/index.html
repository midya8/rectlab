EVIDENCE, WITH BOUNDARIES

Inspect the proof machinery.

Two algorithms, two jobs

The generator uses ordered skip/take dynamic programming. The Python checker independently discovers rectangles from positive-cell subsets and counts covers with inclusion-exclusion. Forced-factor inclusion-exclusion checks each membership count; a first-cell recursion checks partition counts, and determinant minors check arithmetic rank. Count-guided rank/unrank makes every optimum accessible.

python -m rectlab solve input.json > report.json
python -m rectlab verify report.json

Existing mathematics

Exact Boolean rank equals all-one rectangle cover number. This is a small evidence interface for established results, not a new factorization algorithm or a scalable solver. Maximal-factor and unrestricted-factor counts are deliberately separate.

Not a learned representation
